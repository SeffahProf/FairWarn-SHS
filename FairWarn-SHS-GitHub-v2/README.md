# FairWarn-SHS GitHub Project — Version 2

This package contains:

- corrected processed node data;
- valid peer edge list;
- feature-only baseline notebook;
- standard GraphSAGE baseline notebook;
- standalone GraphSAGE training script.

## Run the GraphSAGE notebook

Open:

`notebooks/04_graphsage_baseline.ipynb`

Upload these two files when requested:

- `FairWarn_SHS_Node_Features.csv`
- `FairWarn_SHS_Edge_List.csv`

The notebook should report 398 nodes, 396 labelled nodes, and 1,129 undirected edges before training.
